## 2. 建议、方向和原型选择（不可当作用户已定要求）

- React + Vite + TypeScript：文档建议，本轮选用以完成 M0；未来可调整技术实现而不改变产品行为。
- 每天 30 新词、90% 目标保持率：建议初值，不是硬约束；本轮不实现。
- 输入联想、拼写纠错、变形识别：已提出且未被否决的方向，非必须在 M0 完整交付。本轮只做样例搜索与列出词形识别。
- `.txt` 下载、预计学习耗时、附带英文释义的导出：建议或后续增强。
- “学习日期”按本地时区和有效活动界定：建议，M2 实施前明确并做边界测试。
- Supabase / Cloudflare 后端、静态托管平台、具体数据库表结构：技术候选，未锁定。
- 当前名称“英语词典 · M0 原型”、绿色与米白配色、卡片布局、导航：临时草案，页面和 manifest 均注明原型。
- Wiktionary / WordNet / Tatoeba：候选内容源，尚未导入、尚未完成授权与质量检查，不声称已获得其数据。

## 4. 环境检查和本轮选择

- 初始目录为空，无 Git 仓库、现有框架或部署配置；祖先目录和工作区未找到适用的 AGENTS.md。
- 检测到 Node 24.22.1、pnpm 11.25.0、Git 2.55.0；npm 命令未出现在 PATH，使用现有 pnpm。
- 初始化本地 Git `main` 分支；不创建远程仓库，不自动提交或推送。
- React 19.3.1、Vite 8.3.7、TypeScript 5.9.3；依赖精确版本以 lockfile 为准。Vite 当前引擎要求在 registry 中核实为 `^20.19.0 || >=22.12.0`，本机符合；参见 [官方入门](https://vite.dev/guide/)。Node 主版本限制为 24，避免未经测试的工具链漂移。
- 使用 hash 路由，部署时无需自定义深层路径重写；使用 React 转义文本，用户查询不作为 HTML 注入。
- 无第三方字体、远程图片、视频脚本或 AI API。初始资源在本地包中，不混入商业词典内容。
- manifest 使用相对路径，安装 ID/scope/start_url 与部署基路径保持一致。M0 不注册 service worker，不承诺离线。
- 本轮部署交付形式为静态 `dist/` + HTTPS；实际账户/托管服务及公网地址尚未落地，因此安装验收仍为开放项。

## 5. 模型与后续扩展边界

- **内容身份**：`DictionaryEntry.id` 独立于 `Sense.id`。短语有自己的 entry ID；派生词有独立词条；词形只关联词元并保留 surface label。
- **出处**：每个 entry / sense / example 都有来源、许可说明、署名和测试标志；真实来源可填写引用 URL。样例没有虚构外部引用链接。
- **提供方**：词典、例句、发音和视频四类 provider 契约互相独立。UI 通过异步词典接口读样例；视频只返回外链，不表示真实结果存在。
- **M2 学习模块**：新建私有 learning item，以 entry ID 关联共享内容；另存 source tags / manual mastery / FSRS state；独立追加 review logs，不能从查询记录推导学习活动。
- **M3 同步模块**：认证、用户隔离、稳定 ID、版本冲突和追加日志在独立持久化层实现，不改词典共享内容 identity。前端不得包含 service-role 密钥。
- **没有假服务**：未创建“模拟同步成功”、假 FSRS 调度、假音频播放或假视频结果。后续接口不等于对应功能已实现。
