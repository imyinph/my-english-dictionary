覆盖的关键断言：

1. 搜索大小写/空格规范化；短语搜索可进入独立详情。
2. 中文释义、每条例句译文初始隐藏且独立展开。
3. 展开中文 → 点击派生词 → 浏览器后退，原词条中文重新隐藏。
4. 短语详情可直接加载、刷新，关键词跳转后可返回。
5. `created` / `creating` 回到 `create`，保留 surface；`creative` 不并入 `create`。
6. 例句中的样例词可点；义项的近反义词可点。
7. 未命中、异常路由、无效编码都有可恢复状态，不编造词义。
8. 搜索/导航不写 localStorage 或 sessionStorage，不创建假学习记录。
9. 视频区域默认折叠；外链 US URL 正确编码；`noopener noreferrer`；无 iframe 或第三方资源请求。
10. manifest 与图标存在，standalone/scope 设置符合本轮配置。
11. 手机窄屏无横向滚动，主流程无浏览器异常。
12. 返回首页后搜索文本保留，再进详情中文仍隐藏。
13. “搜索词典”和品牌链接均可返回首页。

数据测试额外验证所有关联引用有效，entry/sense/example identity 唯一，样例来源标记完整，例句按义项读取，US/UK 视频外链参数分开。

## 用户手工验收：本地原型

在项目目录执行 `pnpm dev` 后打开 <http://localhost:5173/>。

| 操作 | 预期 |
| --- | --- |
| 首页输入 `create`，打开词条 | 英文释义优先；2 个义项，各 2 个例句；中文未展开 |
| 展开第一条中文释义 | 仅该释义中文出现，例句译文仍隐藏 |
| 展开一个例句译文 | 其他译文保持隐藏 |
| 在 Word Family 点击 `creative`，再点返回 | 回到 `create`；中文重新隐藏 |
| 输入 `created` | 进入 `create` 并看见原形式 `created` |
| 输入 `make sense`，进入并刷新页面 | 保留独立短语详情；可点击关键词 `make` / `sense` |
| 从 `make` 的 Phrases 区进入 `make sense` | 路由是短语自己的 ID，不是静态注释 |
| 输入未提供的 `elephant` | 明确显示无测试数据，可清空后恢复 |
| 展开 Real-world English | 显示许可待确认及外链，不自动加载视频 |
| 检查页头/页尾/来源说明 | 明确为 M0 测试数据和临时视觉方案 |
