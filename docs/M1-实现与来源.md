# M1 实现与来源

交付整理：2026-11-11（Asia/Shanghai）。快照及首次网络探测采集于 2026-11-10，精确时间见数据记录。

后续状态更新：用户已反馈此前 M1 电脑/iPhone 主要功能验收通过，但 Safari/PWA Web Speech TTS 听感失真。后续音频增量已将 iOS TTS 降级改为每次主动选择，并建立未生成的候选试听计划；见 [音频试听指南](M1-音频试听指南.md)。下文播放流程是首次 M1 基线；不代表新候选音频已经试听或批量接入。

## 范围与数据流

保持已确认的英英优先、中文默认隐藏、词条/义项身份分离、词族/词形分离和短语独立导航。本阶段只完成有限真实词典接入与发音，不启动 M2。

数据流为：逐词 JSONL → 导入时字段筛选和出处记录 → 同源静态快照 → Kaikki 适配器 → DictionaryProvider → UI。页面不直接解析商业词典网页，不使用 AI 生成释义或例句。

原始十词 JSONL 合计 **584,316 字节**，不是大型词典数据库。交付快照约 **184 KB**，17 个词性/词源记录适配为 10 个词条、113 个义项、95 条展示例句、13 个核验许可的录音条目。快照与 UI 解耦，可以替换 provider 而保持页面行为。

## 缺失字段与质量边界

1. 仅纳入 `type=example` 且无 `ref` 的例句，排除 **129 条外部引文或类型不明记录**；不把当代作品引文自动归入词典许可。
2. 保留词性、多个义项和原始用法标签。分层 gloss 的末项为主释义，上级内容作为语境说明。词典原文不一定符合最终学习者友好文风，尚未做合法可追溯的学习者改写。
3. 中文仅取义项自身记录，或词条级 `sense` 与末级 gloss 精确匹配的记录；只规范大小写、空格、末尾标点。当前只有 3 个义项匹配成功；中文例句译文全部缺失，UI 明确说明。
4. 近反义词按来源义项组织。没有明确 sense 对应的词条级关系不会扩散到所有义项；范围外条目通过标记 ↗ 的链接到 Wiktionary 查看。
5. Word Family 只展示源站 related/derived 中属于十词范围的条目，不从字符串相似性推导关系。Word Forms 排除替代拼写和表格控制标记，保留原形式和语法标签。
6. 目标词高亮读取源数据的 Unicode 码点偏移。例句按词数排序，每义项最多 4 条；不足 2 条显示说明。该排序不代表专业难度分级。
7. 缺失音标、义项、例句、翻译或录音许可均不以 M0 测试内容补齐；快照请求失败明确报错，可刷新重试。

## 录音来源与统一朗读

[Commons 复用规则](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)要求逐媒体查看许可。通过 [imageinfo API](https://www.mediawiki.org/wiki/API:Imageinfo)核对每个音频的作者、许可、文件页及限制；文本许可不用于推断音频许可。

本轮许可类型包含 CC BY-SA 3.0 / 4.0、CC BY 3.0 US、CC0 与明确的公有领域声明。作者、所选许可 URL、文件页、原始 credit、核查时间及元数据 SHA-256 保存于 `audioLicenses`，页面可以展开查看。

`en-us-creation.ogg` 的机器可读作者字段仅给出推定署名，未作为已核验录音启用。短语 `make sense` 使用 Commons 上署名 Steve Shives 的 CC0 音频；其原始 credit 提及 YouTube，本应用只访问 Commons 文件，不抓取或嵌入 YouTube。

播放步骤：

1. 点击后选取当前口音的已核验录音，尝试 MP3、再尝试 OGG；无自动预加载。
2. 缺失、加载超时、解码/播放失败时提示并回退浏览器 TTS。
3. US 严格选择 `en-US`，UK 选择 `en-GB`，兼容下划线标签并优先本地声音；不将任意英语或中文默认声音冒充目标口音。
4. 处理初始空声音列表、`voiceschanged` 和仍缺少声音的情形。失败时提示安装相应系统语音或手动切换，不宣称已播放。
5. 处理 TTS 启动/错误/超时；全局状态及当前按钮旁均显示反馈。例句只用 TTS，并明确标为合成语音。
6. 同时只保留一个播放任务，停止、切换口音/速度、导航或隐藏页面取消旧任务，旧回调不覆盖新状态。

浏览器 TTS 的声音和在线依赖来自设备/系统，[getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)返回当前设备可用声音，不保证所有设备都有 US/UK。

## 维护与未解决问题

导入白名单固定 10 词，限制单响应 2 MB，校验原始快照 SHA-256，并原子替换生产 JSON；失败不覆盖旧版本。离线缓存模式缺缓存会失败，不暗中联网。网络探测遇到第一次 429 后停止剩余请求，不绕过服务限制。

义项 ID 当前包含词条、词性、词源/记录位置、gloss 指纹和义项位置；上游重排可能改变 ID。M2 前需要稳定身份与快照迁移设计，当前不能直接用于长期学习记录。

录音许可已核对不等于网络和播放已验证。真实网络存在限流；本机自动化未确认真实出声、声音质量或设备地区语音。尚无 HTTPS 部署与 iPhone 安装/播放真机验收。

没有新增生词本、AI 近义词辨析、YouGlish 嵌入、账户、同步、FSRS 或学习导出。只在本地保存口音和速度；这不是账户同步。M1 到此停止。
