# M1 音频供应商与候选音色

核查日期：2026-11-11。此文是供应商资料研究与试听设计，**不是已试听后的音质排名**。本轮没有可用 API 凭据、没有发送合成请求、没有生成真实候选音频。

## 决策边界

- 已确认：质量目标 B；合法且读音正确的真人录音优先，预生成神经网络音频补充，浏览器 TTS 最后备用；默认 US、可选 UK、可调速；先小样试听，用户选音色后才能批量接入。
- 本轮技术选择：Azure 标准 Neural 与 Google Chirp 3 HD 各两种男女音色；文件型 MP3、静态清单、无数据库与在线付费后端。具体音色仍是候选。
- 用户反馈：此前 M1 自动化及电脑、iPhone 主要功能验收已通过；Safari/PWA 和独立 MDN 演示的浏览器 TTS 均有失真。不能据此断定预生成 MP3 的音质。
- 待决定：US 与 UK 最终音色，可以分开选择；生成地区、账户计费方案、Cloudflare 实际部署地址。未进入 M2。

## 候选与比较方法

| 提供商 | US 候选 | UK 候选 | 本轮比较重点 |
| --- | --- | --- | --- |
| Azure | en-US-JennyNeural（女）、en-US-GuyNeural（男） | en-GB-SoniaNeural（女）、en-GB-RyanNeural（男） | 单词音节、重音控制、词典式清晰度 |
| Google | en-US-Chirp3-HD-Aoede（女）、en-US-Chirp3-HD-Charon（男） | en-GB-Chirp3-HD-Aoede（女）、en-GB-Chirp3-HD-Charon（男） | 连读、长句自然性，同时排查漏词和不受控停顿 |

候选名称依据上述官方清单和 HD 页面；每条记录的 `voiceVersion=null` 表示服务未提供可锁定的底层版本，不将音色名称伪装成固定模型版本。优先评测 Azure 是基于控制能力和成本的技术建议，**不是听感优胜结论**。

共 12 段材料 × 8 个音色 = 96 个文件的上限：

1. 现有 create、creative、creativity、make sense，比较词族重音与短语连读。
2. creation 的常规例句、create 的长例句，原文原样保留，测试缩写、句尾语调、分号停顿和专有名词。
3. 自编 record 名词/动词语境句各一段，检验模型自动消歧。
4. record 名词/动词、read 原形/过去式四项指定 IPA 的单词测试，分别保留读音 ID。属于评测材料，不进入词典搜索和正式词库；IPA 只表达测试目标，仍需听读核验。

先生成每家 8 个小样确认 API 和 MP3，之后最多补齐此 96 个试听文件。即使全部满意，也须用户明确选择音色才能开启现有词库批量生成。不得把“试听满意”直接改成所有内容已审核。
