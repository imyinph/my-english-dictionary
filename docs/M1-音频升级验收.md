# M1 音频升级：试听阶段验收

日期：2026-11-11。执行边界：完成试听所需实现与资料，缺凭据不伪造音频；不进入正式词库批量生成或 M2。

## 已实现

- Azure Neural / Google Chirp 3 HD 当前价格、US/UK 音色、控制能力和输出许可研究；记录 Azure F0 与付费层输出权利差异、Google SSML Preview 的待验证点。
- 12 段材料、8 个候选音色、96 个任务的固定试听计划。6 段材料来自既有 M1；6 段为独立诊断，不增加正式词条。
- `/#/audio-lab` 试听入口，US 默认、UK 切换、共享调速/停止、单文件播放、缺失与失败反馈；本机笔记、刷新保留和 JSON 导出。
- 内容、义项、读音、口音分离的资源契约；真人优先、神经音频其次的解析器；只有已审核资源可用于正式词典，试听候选可独立播放。
- 本地 MP3 生成脚本、安全环境配置、默认 dry-run、显式小样生成、预算预估、有限重试、SHA-256 去重、原子写入与生成锁。没有付费实时后端。
- iOS 上浏览器 TTS 需每次主动选择；录音失败也不能静默启用。切口音/速度、重复点击、返回和页面隐藏取消旧播放。
- 保留十词快照、现有 Commons 录音和逐文件署名；保留搜索、中文折叠、词族、词形、短语详情、返回和 PWA 配置。

## 未验证与未完成

1. 本地未检测到 Azure/Google 语音凭据；实际合成请求 **0**，真实神经音频 **0 / 96**，实际合成支出 **0**。API 成功、服务地区可用性、账户层级/余额、完整 MP3 解码及真实成本尚未验证。
2. 测试替身只验证适配与控制流。测试字节未作为试听文件发布；不能据此评价音色、自然度或 iPhone 扬声器质量。
3. 用户已报告此前 M1 电脑和 iPhone 主要功能通过、Web Speech 失真。本轮没有新增 iPhone 真机试听结果；新的每次 TTS 选择及 MP3 页面还需真机操作。
4. Google 同步 SSML Preview、US/UK IPA 实际效果、长句专有名词读音均须核验。未知底层音色版本明确存为 null。
5. 没有最终音色决定、正式神经音频 manifest、整库生成、R2 上传或新 Cloudflare 部署。接口和迁移路径已备好，不宣称迁移已完成。
6. 既有真人录音许可保留，但本轮没有重新逐条听审其义项/读音正确性；上游词典 ID 重排仍需人工迁移。

## 手工验收入口

按 [试听指南](M1-音频试听指南.md)运行，打开 `/#/audio-lab`。无凭据时应显示未生成、播放按钮不可用；配置凭据后先生成每家最多 8 个小样，再刷新听审。用户确定最终 US/UK 音色后，才另外规划正式批量生成。
