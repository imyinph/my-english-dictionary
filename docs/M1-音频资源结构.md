# M1 音频资源层与迁移

契约：`src/domain/audio.ts`。实现：`src/providers/audioResolver.ts`、`src/providers/pronunciation.ts`。试听清单与运行时校验：`public/data/audio-audition.json`、`src/providers/auditionManifest.ts`。

| 字段 | 用途与约束 |
| --- | --- |
| id | 请求配方的 SHA-256；不以拼写作唯一键 |
| target.contentId / kind | 词条、独立短语、例句或诊断身份；诊断永不进入词典 |
| target.senseId / pronunciationId | 义项可选、读音必填；匹配时两个字段均严格相等，不把缺义项当通配符 |
| locale | en-US / en-GB；默认 UI US，UK 必须主动选择 |
| text / textSha256 | 原文与摘要；内容变化须新资源 |
| source / provider / model / voice | human 或 neural、来源与音色名；未来真人源可用同一契约 |
| voiceVersion / recipeVersion | 未提供固定服务模型版本时为 null；配方版本由项目维护 |
| asset.path / format / sha256 / bytes | 可迁移相对 object key、格式、内容哈希、长度；未生成没有 asset，不填假 URL |
| license | 音频服务条款 URL、署名、文本来源/许可、核查日期；保留音频/文本权利区分 |
| generation | planned / ready / failed、成功时间、尝试次数、脱敏错误 |
| review | pending / approved / rejected、审核人/时间/设备/备注；生成成功不等于审核通过 |

`AudioResolver.resolve(target, locale)` 只返回严格匹配的、已生成且已批准资源，真人优先神经网络音频；`audition(resource)` 可预览未审核候选，但拒绝被驳回、无文件或校验元数据不完整者。Pages 相对路径由唯一资源层转换为实际 URL；更换 R2 基础地址无需在详情页拼供应商 URL。

`AudioPlayer.playResource(resource, rate)` 与词典 `play(request)` 共享一个可取消的播放器。重复点击取消旧播放并重播，停止、切口音/速度、页面隐藏和导航都会终止旧任务，过期回调不能覆盖新状态。试听错误终止播放，无 TTS 替代；词典匹配音频耗尽后，iOS 需要每次主动选择浏览器备用 TTS。

现有 M1 `Recording` 保持原数据与署名，通过兼容路径映射为真人候选。仅未分义项的 `entry-default` 可使用该路径，新的具体 pronunciationId 不继承它。M1 许可核验与用户主要功能验收不等于所有录音的逐义项发音已经专业审核；后续正式资源导入需逐项记录。

当前正式播放器的 manifest 注入为空，**不会将试听候选装入正式词条**。详情页已传入内容/义项/读音身份；用户选定后，在提供方组合处加载正式 manifest 并注入 `ManifestAudioResolver` 即可。没有把“接口已建好”写成“全部内容已生成”。

文件校验在生成与去重阶段读取完整 SHA-256；浏览器资源层仅校验清单结构，不下载整个文件再做 WebCrypto 验证，以免延迟 iOS 用户手势播放。部署时须校验真实对象，使用内容哈希文件名并避免覆盖。供应商音色不能固定版本时，保留已审核文件比重新合成更可复现。

现有词典义项 ID 包含上游位置；上游快照重排时需人工核对映射。不得只靠文本相同自动迁移审核结论。任何 ID、文字、IPA、音色、音色底层版本或配方变化，都要重新检查和试听。
