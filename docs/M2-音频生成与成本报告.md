## 预算

按 [AWS Polly 当前 Neural 价格](https://aws.amazon.com/polly/pricing/) USD 16 / 百万字符计，不扣免费额度或 Credit，不将其当无限调用授权。

- 8,900 计费字符（两个音色合计），一次成功估算 **USD 0.1424**。
- 每项最多 3 次尝试，保守预留 **USD 0.4272**。
- 默认单次运行预算 USD 5。开始前及每次请求前都检查；超限停止，只有明确更改 `--budget-usd` 才提高上限。
- `.audio-state/polly/ledger.jsonl` 在每次网络请求前同步记录字符/费用预留，含重试与无法确定是否到达 AWS 的请求。成功响应的 RequestCharacters 单独累积。这是保守请求估算，不是 AWS 实时账单。
- 正常退出或下次运行会根据持久化日志重建累计数。没有收据的未知中断需要明确 `--retry-uncertain`，不能承诺网络故障下服务端“恰好一次计费”。

## 执行

```powershell
pnpm audio:plan
pnpm audio:preflight --profile dictionary-polly
pnpm audio:generate --profile dictionary-polly
pnpm audio:verify
pnpm release:build
```

默认区域 ap-southeast-2（悉尼）；使用 `--region`、`AWS_REGION` 或 `AWS_DEFAULT_REGION` 可覆盖，优先级依此排列。当前脚本明确传入区域，因此仅修改 Profile 文件中的 region 不会覆盖以上默认值。本轮按用户确认统一修改项目默认值；本地 dictionary-polly Profile 已是悉尼，进程/用户/系统级区域环境变量均未设置，没有旧区域环境覆盖。

并发最多 2、启动间隔至少 500ms，重试也占限速槽。SDK 自带重试关闭，由任务层记录最多 3 次尝试及指数退避。生成成功原子落盘并写收据；重复运行先校验已有资源，命中不付费。本轮累计日志记录 210 次尝试、210 个不同资源、210 次成功，失败与重试均为 0；AWS 实际账单及 Credit 抵扣另行核对。
