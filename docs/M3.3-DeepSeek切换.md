## 配置

根目录 `.env.deepseek.local` 已创建并被 Git 忽略；只在本机填写 `DEEPSEEK_API_KEY=`。不要把密钥放入聊天、public、源码或构建。新 CLI 只读取 DeepSeek 本地文件，不依赖原 Gemini 密钥。

按 [官方模型页](https://api-docs.deepseek.com/quick_start/pricing/)（2026-11-15 核对）默认使用 `deepseek-flash`，页面列出的版本为 DeepSeek-V4.1-Flash-1017；不沿用旧 deepseek-chat 别名。请求为 `POST https://api.deepseek.com/chat/completions`，Bearer 认证仅在内存请求头中构造。

使用 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/) 和本地结构/ID/POS/原文/中文完整性校验；JSON 模式不等于服务端严格 JSON Schema。空白 content、非 stop 结束、身份不符、超过三个简释均失败停止。未启用 web tools、Grounding；显式 tool_choice=none、thinking=disabled。thinking 可用性见 [官方 Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。

DeepSeek 是按 Token 计费的 API，不承诺免费。官方 Flash 当前峰时每百万输入（未命中缓存）US$0.30、输出 US$1.20，非峰时半价。本项目先运行一批五条，保存实际 usage；不充值、不更改套餐。配置的请求/Token 上限是保护阈值，不是已承诺的账单金额。

## 调用及停点

```powershell
pnpm m3:plan                   # 离线，显示配置是否存在但不显示密钥
pnpm m3:probe --execute        # 单条 staging，一次请求
pnpm m3:pilot --execute        # 五条 staging，一次请求
pnpm m3:report                 # 新流水线报告，离线
pnpm m3:legacy-report          # 原 Gemini 历史报告，离线
```

默认单并发、4 RPM、批次不超过五条。关闭自动重试；401/402/429/5xx、网络异常或无效输出保存完整脱敏响应后停止。staging 目录已存在时拒绝重复执行。用户更新错误配置并明确继续后，可显式指定 `--attempt=2` 创建新的独立测试目录，保留此前证据；这不是自动重试。

全量入口已切为 DeepSeek，但本次不运行。验收后才使用 `pnpm m3:run --execute --allow-batch`；该开关不能解释为当前已经完成用户验收。选定失败项的明确恢复为 `pnpm m3:retry --execute --allow-batch <sense_id>`，保留暂停和历史事件。人工导出审核包仍由 `pnpm m3:accept --execute --file <file>` 导入；没有审核包不发布任何正式译文。
