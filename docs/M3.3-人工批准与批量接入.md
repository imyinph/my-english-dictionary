## 安全配置与运行

在项目根目录本机创建 `.env.translation.local`（已被 .gitignore 忽略，不能放在 public/）并填写 `OPENAI_API_KEY=你的密钥`。不要在聊天发送密钥；不要使用 VITE_ 前缀。文件只供 Node 本地脚本加载，Vite 不会自动加载这个自定义文件名。可以改用临时进程环境变量，不必保存文件。

Node 24 下：

```powershell
pnpm zh:ai:plan
# 仅在用户确认首批预算、完成本机配置以后执行：
node --env-file=.env.translation.local scripts/aiChinese.mjs --run --limit 20 --budget-usd 1
```

不传 `--run` 始终只产出 `artifacts/m33-ai-plan.json`，报告当前进程是否存在密钥但不打印内容。实际运行会保留全部请求；结束后必须检查首批语义复核质量，再决定扩展剩余内容。脚本当前每次最多 20 条，禁止一次跳至 98。

自动审核结果的正式发布状态及导入入口尚待首批验证后接入；当前脚本不会绕过原正式中文的人工批准规则。批量内容未来须使用单独的自动审核状态/证据，不能套用这次用户批准。
