# M3.3 双引擎实施前审查

2026-11-14；依据用户本次 Dual-Engine Chinese Translation Pipeline 任务书。

现有 React/Vite 静态 PWA；固定 10 词、113 Sense、95 例句。正式中文独立 JSON，由追加版本历史、导入证据及人工审核包导出；15 条已人工批准，其中 12 条已有扩展解释。M3.1 与 ECDICT M3.2 均实际实现，不需重建。ECDICT 原始候选在本机 artifacts，来源许可未完全厘清，不能混入正式静态词典。原 OpenAI 批量脚本仅未启用草案，本任务用 Gemini Express + Azure 取代。

测试基线：106 单元/脚本、111 浏览器场景均通过（上轮新增 3 场景修正选择器后定向通过）。音频 210/210 解码和 6/6 原生播放通过。线上仍为 M2，本轮中文未部署。仓库无 Git 提交，恢复以显式 ZIP 和内容备份为准。

M2 的 Joanna 与 Stephen 都是 en-US；用户任务背景把 Stephen 写成 UK，与实际音频不符。不改音色/录音/清单/播放逻辑。双引擎仅处理中文，不改英文或 Sense ID。

设计：本地 scripts/m3 模块负责配置、两客户端、严格结构验证、持久请求缓存、串行调度、费用/字符保护、语义比较和冲突复核；每条处理状态在本机忽略目录保存。Gemini 主生成字段包含 azure_translation/ecdict_candidates，但独立首轮显式设为空并标注 withheld，防止两个结果互相抄写；比较/复核才提供两引擎原始结果、相邻义项及候选。这处理了任务书“独立生成”与“首轮提供参考”的张力，优先遵守独立性。

确定性检查可以发现 ID、类型、缺失、长度、重复和来源变化；不能单靠规则证明没有额外含义。额外含义、遗漏和语域由带证据的语义检查负责；自评分不是通过阈值。复核仍为同一 Gemini 模型的独立请求，不冒充第三家独立引擎。罕见/专业不确定结果进入 needs_review，不强追 100% auto_pass。

全部 113 Sense 均建状态：已有 15 条为 user_accepted，保留原授权，不重新付费生成；其余先 10 条试验，再 98 条剩余集合。自动通过只是候选；本地验收页支持筛选异常、修改、接受符合条件项、拒绝、导出审核包和重试清单。用户操作后才导入正式历史；生产部署必须另经用户验收。

凭据检查：本轮开始时项目根目录没有 .env.m3.local，当前进程也没有两家密钥。只输出配置存在状态，未读取/显示任何密钥。提供 config/m3.env.example；.env.* 已被忽略。不得创建云资源、切换 API 产品或升级套餐。
