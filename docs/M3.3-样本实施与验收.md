## 运行、验收与回滚

使用 Node 24：`pnpm dev` 后打开 `http://localhost:5173/#/chinese-samples`。可在同一局域网的 iPhone Safari 打开 Vite 给出的 LAN 地址查看；正式 PWA 验收仍须 HTTPS，当前线上仍为 M2。

命令：`pnpm zh:samples:publish` 只重复生成已复核静态样本；`pnpm zh:samples:verify` 验证；`pnpm test`、`pnpm release:build`、`pnpm test:e2e` 执行回归。正式构建会同时校验样本和原中文，不能绕过原审核门槛。

人工抽查重点：create 总义不是只指凭空创造；creation 行为义不等于作品；make 描绘义不等于实际致使；make 软件名词与作诗动词分开；作诗保留 obsolete；destroy 动物处置义不等于普通物品损坏；make sense 的合理义与理解动作分开。

验收交互：12 张卡片均显示英文和简释；解释逐张独立展开/收起；来源可见；原有缺失例句未伪造；进入词条可播放 M2，返回导航正常；320px 不横向溢出。自动浏览器模拟不代替 iPhone 真机验收。

变更前备份：`artifacts/source-backups/before-m3-3-samples.zip`。可选择性恢复本轮修改的旧文件并移除新样本入口；正式中文历史未迁移，无数据库回滚。不要覆盖之后的新工作。恢复后重新构建验证。线上未部署，无需线上回滚。
