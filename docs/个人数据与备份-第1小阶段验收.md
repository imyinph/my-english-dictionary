# 个人数据与备份 · 第 1 小阶段验收

[正式站个人数据与备份](https://my-english-dictionary.pages.dev/#/personal-backup) · [本地预览](http://127.0.0.1:4186/#/personal-backup)

## iPhone 验收

- [ ] 从正式站首页底部进入「个人数据与备份」。将 `create` 以「收藏」保存，`make sense` 以「加入待学」保存，再将未收录的 `Resilient` 以「加入待学」保存。在空库上应看到「已匹配 2 条 · 待匹配 1 条」。
- [ ] 展开「查看保存内容」核对三条记录。再收藏 `created` 应归入已有的 `create` 条目；再保存小写 `resilient` 应保留一条待匹配词和首次拼写。在同一入口刷新、退出并重开，记录与状态应一致。
- [ ] 点「准备 JSON 备份」，再点「下载 JSON 文件」，在 iPhone「文件」中找到备份。导出的是本次准备时的个人记录快照。
- [ ] 在另一台设备、另一浏览器或干净的浏览器配置中打开正式站，选择这份备份。先看新增、更新、移除数；点击「取消恢复」，原库应保持原样。重新选择文件，确认整库恢复，再核对三条记录、收藏和学习意向。
- [ ] 从主屏幕图标重开，验证在该入口保存的记录仍可读取。各入口使用的浏览器存储可能独立；请在同一入口测试重开，在不同入口测试文件恢复。

**整库恢复会替换当前个人词汇记录。** 若目标浏览器已有需要保留的数据，先导出其备份，或使用新的浏览器配置验收。此版本的备份范围是词条身份、收藏和学习状态、待匹配词的原始拼写与意向，以及记录创建和更新时间。

## 实现与边界

- 使用 IndexedDB 数据库 `dictionary.personal`，数据库和 JSON 格式均从版本 1 开始。首次打开建立个人数据仓储。上一阶段只保存了音频偏好，本阶段不需要迁移既有个人词条。
- 每次保存都在读写事务内合并到最新记录。恢复预览记录本机修订号；确认前如有其他页面写入，要求重新预览。校验错误、取消或事务失败均不提交替换。
- 备份恢复验证格式、版本、时间、状态组合、词条身份及重复记录。未收录拼写单独保存，可随备份往返。词典数据暂时不可用时仍可导出已有个人数据。
- 当前入口可单条写入验收记录。词条详情页状态按钮、批量词表导入与待匹配词重新匹配属于后续小阶段。
